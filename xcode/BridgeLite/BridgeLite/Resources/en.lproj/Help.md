## Navigation

- **← →** Move to previous / next photo
- **↑ ↓** Move to previous / next photo (row by row in grid)
- **Shift + ← → ↑ ↓** Extend selection while moving
- **Cmd + ← →** Jump to first / last photo in group

## Selection

- **Click** Select a photo
- **Cmd + Click** Toggle selection (add / remove)
- **Shift + Click** Select a range
- **Cmd + A** Select all
- **Cmd + Option + A** Deselect all

## Rating & Labels

- **0–5** Apply star rating (0 to clear)
- **6–9** Apply color label (6=Red, 7=Yellow, 8=Green, 9=Blue)

## View Modes

- **Space** Enter viewer mode
- **Escape** Exit viewer mode
- **Return** Enter compare mode
- **Double-click** Enter compare mode
- **Tab** Switch between RAW / JPG / Developed (Shift for reverse)

## Compare Mode

- **Ctrl + Tab** Move between groups and members
- **Ctrl + Shift + Tab** Move in reverse
- **Escape** Exit compare mode

## File Operations

- **Cmd + C** Copy selected photos
- **Delete** or **Ctrl + D** Move selected photos to Trash
- **Cmd + Z** Undo last action

## Other

- **Drop a folder onto the window** Open that folder
- **Right-click (or Control-click)** Show context menu
