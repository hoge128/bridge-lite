# 比較モード（Mac・新規）設計検討

Status: 検討（未実装）/ 2026-06-13

## 既存機能との区別

| | 既存: GroupCompareView | 新規: 比較モード（本ドキュメント） |
|---|---|---|
| 目的 | 同一ショットのバリエーション比較（RAW / JPG / 現像） | **別ショット同士**の比較（似たカットから「残す一枚」を選ぶ） |
| 対象 | shot group のメンバー | ユーザーが任意に複数選択した写真 |
| 起点 | ダブルクリック / Return | 複数選択 + ショートカット（C を想定） |

bridge-lite のコンセプト（大量撮影からのセレクト高速化）に対して、現在
「連写した 5 枚からベストを選ぶ」操作は 単体ビューを行き来するしかない。
ここが Lightroom の比較表示 / 調査表示（Survey）に相当する欠落ピース。

## UI 案

### 起動
- グリッドで 2 枚以上選択 → `C` キー（または右クリック「Compare Selected」）
- 1 枚選択で C → 直前/直後の写真と 2 面比較（連写セレクトの最頻ケース）

### レイアウト
- 2〜4 枚: 横並び等分割（5 枚以上は警告するか先頭 4 枚）
- 各ペインに: ファイル名 / 星 / カラーラベル / Pick・Reject バッジ / EXIF ミニバー（SS・F・ISO）
- フォーカスペイン（キーボード操作対象）は accent 枠で明示

### 同期ズーム / パン（差別化ポイント）
- 全ペインで ZoomState を共有し、1 ペインのピンチ／ホイール／ドラッグが
  全ペインに同時反映（ピント・目つぶり比較の要）
- `⌥` ドラッグで一時的に個別パン（構図ズレ補正）→ キーを離すと再同期

### セレクト操作（Survey 方式）
- フォーカスペインで `X` → そのペインを縮退して候補から外す（Reject フラグも付与）
- `P` / `1-5` / `6-9`: フォーカスペインに適用（既存のグローバルキーモニタがそのまま効く）
- 最後の 1 枚になったら自動で単体ビューへ昇格 or 終了
- `←` `→`: フォーカスペイン移動、`Tab`: ペインの写真をグループ内バリエーションで循環

## 技術設計

### 再利用できる既存部品
- `ZoomableImage` + `ZoomState` — ZoomState を ObservableObject 的に共有すれば同期ズームは小改修
- `LargeImageDecoder`（maxConcurrent: 1 直列化）— フル解像度デコードの IOSurface 枯渇対策は実装済み
- P/X/星/ラベルのグローバルキーモニタ（ContentView）はモード非依存で動作済み

### 制約（knowledge/iosurface-e00002c2-compare-viewer.md / thumbnail-cache-iosurface.md）
- フル解像度の同時保持は IOSurface とメモリの両面で危険。
  **3 ペイン以上は 4096px ダウンサンプルを必須**とし、
  フル解像度はフォーカスペインのみ遅延昇格（two-tier 案 = project_fullres_two_tier_future と合流可能）
- 60MP クラスでは 1 枚 240MB（ビットマップ）になるため、4 面フルは不可

### 状態管理
- `LibraryStore.compareSelectionMode: Bool` + `compareCandidates: [UInt64]` を追加
- 既存 `compareMode`（グループ比較）とは独立したフラグにする
  （同居させると Esc / toolbar 非表示などの遷移が壊れやすい。iPad での教訓:
  project_ipad_detail_transition）

## 実装フェーズ案

1. **Phase 1（最小・1〜2日）**: 2 面固定・同期ズームなし・X で外すだけ
2. **Phase 2**: 同期ズーム/パン + ⌥ 個別パン
3. **Phase 3**: 3〜4 面 + ダウンサンプル二層化 + フォーカスのみフル解像度
4. **Phase 4**: 1 枚選択時の「隣接カットと比較」導線、Tab でのバリエーション循環

## 未決事項

- ショートカット `C` は現状未使用か要確認（メニュー定義との衝突）
- 比較中のソート順変更・フィルタ変更をどう扱うか（候補リストはスナップショットで固定が安全）
- ウィンドウが狭いときの最小ペイン幅（< 300px なら 2 面に制限）
