## BridgeLite 0.4.5

0.4.5 arrives alongside the first release of BridgeLite for Windows. While the Windows version was being built from the ground up, we used the time to polish the Mac experience — refining UI details that had been sitting on the list, and finally fixing thumbnail cache issues that had been lurking since the very first release. The result is a noticeably smoother feel, especially when scrolling through large folders.

### Recent Folders
- **Open Recent** — the welcome screen and File menu now list the last 5 folders you opened
- Added a **Clear History** button to the welcome screen

### Keyboard Shortcuts
- Added a **Keyboard Shortcut Reference** sheet (accessible from the Help menu)
- Rating, label, delete, and view-navigation shortcuts are now shown inline in the right-click context menu

### Performance
- Thumbnails are now pre-loaded into the memory cache during scanning — scrolling through large folders is noticeably smoother

### Fixes
- Fixed label clear not working when multiple photos were selected and the primary photo had no label
- Fixed recent folder history being recorded even when scanning failed or was cancelled
- Fixed thumbnail memory cache limit not being restored after the OS relieved memory pressure
- Fixed memory cache limit set in Settings not being used as the baseline when the OS applies memory pressure

## BridgeLite 0.4.5（日本語）

0.4.5 は、Windows 版 BridgeLite の初リリースに合わせてお届けするアップデートです。Windows 版の開発と並走するなかで、Mac 版はずっと積み残していた UI の細部を丁寧に整え、リリース当初から潜んでいたサムネイルキャッシュの問題をようやく修正しました。特に大量フォルダでのスクロール時の体感が向上しています。

### 最近開いたフォルダ
- **Open Recent（最近開いたフォルダ）** 機能を追加 — ウェルカム画面と File メニューに直近5件のフォルダが表示されます
- ウェルカム画面に**「履歴を消去」**ボタンを追加

### キーボードショートカット
- **キーボードショートカット一覧**シートを追加（Help メニューから表示できます）
- 評価・ラベル・削除・ビュー遷移のショートカットキーが右クリックメニューに表示されるようになりました

### パフォーマンス
- スキャン中にサムネイルをメモリキャッシュへ先行格納するようにしました — 大量フォルダのスクロールが体感的に滑らかになります

### バグ修正
- 複数の写真を選択中、プライマリ写真にラベルがない状態でラベルクリアが機能しない問題を修正
- スキャン失敗・キャンセル時にも最近開いたフォルダへ記録されていた問題を修正
- OS のメモリ圧迫が解除された後にサムネイルキャッシュの上限が復元されない問題を修正
- 設定で変更したキャッシュ上限がメモリ圧迫時の半減計算に反映されない問題を修正
