BridgeLite 0.4.0

New Features

  • Context menus in all views — thumbnail grid, single view, and compare view now share a unified right-click menu with navigation actions
  • Delete photos from single view
  • Right-clicking an unselected thumbnail now auto-selects it before showing the menu
  • Returning from viewer or compare mode scrolls back to the last viewed photo
  • After deleting a photo, focus moves to the previous photo in sort order
  • Star filter now shows facet counts (e.g. ★3 (12))
  • Boost Mode — increases scan and thumbnail priority when toggled on

Fixes

  • RGB histogram now sampled from the master image rather than the embedded preview, eliminating discrepancies on Sony SOOC JPEGs
  • Histogram filter boundary values corrected (focal length, shutter speed, aperture)
  • Delete in flatten mode now deletes only the selected files, ignoring group members
  • Metadata sidebar scrollbar no longer overlaps the content
  • Small embedded EXIF thumbnails (160 px) are now regenerated from the master
  • UI state is correctly cleared when switching folders
  • Removed Redo (was unreliable)

Performance

  • Faster initial scan via partial RAW reads and SQLite batch writes
  • Reduced CPU impact on other apps through QoS tuning
  • Fixed a deadlock in the scan concurrency limiter that could stall scanning

BridgeLite 0.4.0

新機能

  • 全ビューに右クリックメニューを追加 — サムネイルグリッド・単体ビュー・比較ビューで共通のコンテキストメニューからビュー遷移が可能に
  • 単体ビューからの写真削除に対応
  • 未選択のサムネイルを右クリックすると自動的に選択してからメニューを表示
  • ビューア・比較モードを閉じると最後に見ていた写真の位置に自動スクロール
  • 写真削除後、ソート順で1つ前の写真にフォーカスを移動
  • 星フィルタにファセットカウント表示 （例：★3 (12)）
  • Boost Mode — オンにするとスキャン・サムネイル生成の優先度を上げる

バグ修正

  • RGB ヒストグラムを埋め込みプレビューではなくマスター画像から計算するよう変更。Sony SOOC JPEG でヒストグラムが大きくずれる問題を修正
  • ヒストグラムフィルター（焦点距離・シャッタースピード・絞り値）の境界値の誤りを修正
  • フラット化モードで削除する際、グループメンバーを無視して選択ファイルのみ削除するよう変更
  • メタデータサイドバーのスクロールバー重なりを解消
  • 160px の小さい埋め込み EXIF サムネイルをマスター画像から再生成するよう修正
  • フォルダ切り替え時に UI の残留状態を正しくクリア
  • Redo 機能を削除（動作が不安定なため）

パフォーマンス

  • RAW 部分読み込みと SQLite バッチ書き込みによるスキャン高速化
  • QoS 調整により他アプリへの CPU 影響を軽減
  • スキャンが途中で止まることがあったデッドロックを修正
