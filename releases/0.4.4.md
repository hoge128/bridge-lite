## BridgeLite 0.4.4

### Viewer
- **Fullscreen shortcut** — Press `m` to toggle fullscreen in the viewer
- **Auto Fullscreen on Space** — New setting to automatically enter fullscreen when opening the viewer with the Space key

### About Screen
- Added copyright notice, GitHub link, OSS attributions, and privacy policy link to the About dialog

### Fixes
- Fixed toolbar remaining visible in Viewer / Compare mode when built with the macOS 26 SDK
- Prevented accidental duplicate main windows

## BridgeLite 0.4.4（日本語）

### ビューアー
- **フルスクリーンショートカット** — `m` キーでビューアーのフルスクリーンを切り替えられるようになりました
- **Space でフルスクリーンに切り替え** — Space キーでビューアーを開いたときに自動でフルスクリーンへ移行する設定を追加

### About 画面
- About ダイアログにコピーライト・GitHub リンク・OSS 帰属表示・プライバシーポリシーリンクを追加

### バグ修正
- macOS 26 SDK でビルドした場合に Viewer / Compare モード時のツールバーが隠れない問題を修正
- メインウィンドウが意図せず複数開く問題を修正
