変更履歴

  • 2026-06-16 (20) — フィルムストリップで plain I が info card（viewerShowsMeta）の表示/非表示トグルになるよう修正（以前は無効だった）。ピッカー/ビュワーどちらにフォーカスがあっても有効（focus 非依存の大域キーハンドラ）。Shift+I はメタデータバー表示のまま。
  • 2026-06-16 (19) — メタデータバー（SidebarView）を複数選択中はクリア（単一写真のメタデータを出さず「N枚を選択中」表示）。判定はアクティブ選択集合 activeSelectionCount（ライブラリ＝selectedIDs / フィルムストリッププレビュー＝filmstripPreviewSelectedIDs）。i18n: sidebar.multiple_selected。
  • 2026-06-16 (18) — フィルムストリップでプレビュー面がアクティブのとき、Space で「注目中の写真（filmstripFocusID）」の単体ビューを開くように修正（従来は常にピッカーの primaryID＝最初に選んだ写真を開いていた）。単体ビューの前後送り（←/→）はプレビューの並び filmstripCompareIDs で行い、比較セット（selectedIDs）は壊さない（enterFilmstripPreviewViewer / advanceViewerWithinMembers）。ピッカー面アクティブ時・非フィルムストリップ時は従来どおり primaryID。
  • 2026-06-16 (17) — 横一列ピッカーの水平スクロールバーがステータスバーに被って見切れる不具合を修正。singleRowGrid の ScrollView 高さを「1行＋スクロールバー帯（14pt）」にし、バーが 1 行の下に収まるようにした。
  • 2026-06-16 (16) — 横一列ピッカーでフラット化等のバナーがピッカーヘッダーと被る不具合を修正。グリッド領域を 1 行分の高さに固定（singleRowGrid の ScrollView を rowHeight 固定＋body の ZStack を内容フィット）し、ピッカー区画を「バナー＋1行」の内容高さにフィットさせる（高さ固定値で見込まず、バナーは上に積まれる）。
  • 2026-06-16 (15) — フィルムストリップでビューアの裏にピッカー/グリッドの当たり判定が残る不具合を修正。SwiftUI ScrollView に埋め込んだ AppKit 操作層（GridInteractionNSView・contentHeight 全面サイズ）はビューポート外でもヒットテストが残り、ピッカーをスクロールすると隠れた部分がビューア領域に被ってクリックを横取りしていた。hitTest を override し可視範囲外は素通りさせて解消（水平スクロールの横一列にも有効）。
  • 2026-06-16 (14) — サムネイルグリッド／ピッカー（グリッド表示）の左右余白からドラッグできない不具合を修正。LazyVGrid の中央寄せで生じる余白が col0 セルとして誤判定され、ファイルドラッグが始まっていた。操作層に実際の左インセット（leadingInset）を渡し、余白を「セル外＝ラバーバンド可／クリックで選択解除」に正しく扱うよう修正。
  • 2026-06-16 (13) — ビュワー（プレビュー）にドラッグ矩形選択（ラバーバンド）を追加。空白からのドラッグで範囲選択、Shift/⌘ で追加選択。プレビューは小規模・非スクロールのため SwiftUI DragGesture で実装（セル単クリックは minimumDistance でタップと区別し従来どおり）。
  • 2026-06-16 (12) — ビュワー（プレビュー）の空白領域クリックでもフォーカス（アクティブ面）を失わないように。背景クリックは filmstripPreviewActive=true を保持しつつ、グリッド同様に選択解除（previewDeselectAll）。セルのクリック/Shift範囲/⌘トグルは従来どおり（セル側 onTapGesture 優先）。
  • 2026-06-16 (11) — ステータスバー（フィルムストリップ時）にピッカーのレイアウト排他トグルを追加（サムネサイズの左）。グリッド ▦（既定）／横一列 ▭。横一列は ThumbnailGridView の LazyHGrid 1行＋水平スクロールで描画し、操作層（GridInteractionView）は columns=全件数で単一行として整合。横一列時はピッカー高さを「サムネ高さ＋マージン」に固定（それ以上伸ばせない・リサイズ分割線は非表示）。状態は store.filmstripPickerLayout。i18n: filmstrip.layout.grid/row/help。
  • 2026-06-16 (10) — リサイズカーソルを自作三角から標準 NSCursor（resizeUpDown／resizeUp／resizeDown）に変更（システムのカーソルサイズ/コントラスト設定に自動追従）。可動方向で出し分ける挙動（中間＝上下／下限＝上のみ／上限＝下のみ）は維持。
  • 2026-06-16 (9) — リサイズ仕切りのハンドルを横バー（カプセル）に戻し、仕切りをピッカー／ビュワーのどちらにも属さない独立帯として描画（背景を敷かず窓背景が透ける余白に横バーを浮かせて完全分離）。可動方向の限界表示はマウスカーソル（▲▼／▲／▼）に一本化（ハンドル上の白抜き三角は廃止）。
  • 2026-06-16 (8) — リサイズ仕切りのマウスカーソルを VSCode 風の三角リサイズカーソル（自前 NSCursor・黒塗り＋白フチ）に変更。可動方向に応じて出し分け：両方可＝▲▼／下限（プレビュー最大）＝▲のみ／上限（グリッド最大）＝▼のみ。ホバー時・ドラッグ中の両方で限界をまたぐと方向が切り替わる。仕切り内の ▲▼ ハンドル（塗り/白抜き）は従来どおり。
  • 2026-06-16 (7) — リサイズ仕切りのドラッグ座標空間を .local→.global に変更し移動量を 1:1 に（仕切り自身の移動による歪みを解消）。ハンドルを上下三角化し、限界方向は白抜き三角で「これ以上動かせない」ことを表示。ドラッグ中のリサイズカーソルを push/pop で追従（帯から外れても維持）。ビュワーヘッダー上辺に区切り線を追加し標準ツールバーとの結合を解消。
  • 2026-06-16 (6) — ビュワー／ピッカーにヘッダーを新設（viewerHeader / pickerHeader）。各先頭にフォーカスドット◯（アクティブ＝青塗り／非アクティブ＝灰）を表示し、ピッカーヘッダーに表示中の総数（store.visibleIDs.count）を表示。フォーカス分離の表現を灰色減光・青いフォーカス枠/線から「奥行き（elevation）＋◯」へ全面刷新（アクティブ面が手前に浮く）。リサイズ仕切りはビュワーカードとピッカーヘッダーの境界に。ヘッダークリックでもフォーカス切替可。
  • 2026-06-16 (5) — 非アクティブ面の減光を「背景のみ」に変更（写真の上には被せず色味を保つ）。プレビューは背景色を白→グレー、ピッカーは背景にグレーを敷く。フィルムストリップのメタデータバー表示ショートカットを Shift+I に変更（ライブラリは従来どおり I。plain i はビュワー詳細表示と分離）。
  • 2026-06-16 (4) — プレビュー領域をピッカーと独立した操作面に。グリッド同等の選択（⌘A・Shift範囲・⌘トグル・矢印ナビ）＋レーティング/フラグ（0–9, P/X）をプレビュー選択に適用。アクティブ面をクリックで切替し非アクティブ側を灰色減光。プレビュー画像を高品質ダウンサンプル（~2048px）に。
  • 2026-06-16 (3) — プレビュー領域とピッカーのフォーカスを分離（store.filmstripFocusID 新設）。プレビューのクリックはプレビュー内フォーカスのみ更新し、ピッカーの選択（比較セット）は崩さない。
  • 2026-06-16 (2) — ヘッダーのモード名タイトル廃止。最大枚数 4→20。プレビューを「全枚数フィット表示（スクロールなし・サムネイルのみ）」に変更し、多数枚でも安全に（フル解像度ロードを止め IOSurface/メモリを保護）。
  • 2026-06-16 — 初版。フィルムストリップを NavigationSplitView の detail 化（フィルター／ステータスバー併存）、プレビュー白背景化、リサイズ仕切り、メタデータバー（既定OFF）を反映。
