## フィルタパネル

### 表示切替

- [ ] ツールバーの「フィルタ ▼」ボタンでパネルが表示/非表示になる
- [ ] フィルタ適用中はボタンのラベルが水色になる
- [ ] フォルダを開く前はフィルタパネルのみ表示（カメラリストは「インデックス中…」）

### カメラフィルタ

- [ ] `/Users/itotsum/Pictures/Photo` を開くと SONY・FUJIFILM・CANON が一覧に出る
- [ ] チェックを外したカメラの画像がグリッドから消える
- [ ] 複数カメラのチェックを外せる

### ISO フィルタ

- [ ] `最小: 400` を入力すると ISO 400 未満の画像が非表示になる
- [ ] `最大: 3200` を入力すると ISO 3200 超の画像が非表示になる
- [ ] 数字以外を入力してもクラッシュしない

### 焦点距離フィルタ

- [ ] `最小: 50` を入力すると 50mm 未満の画像が非表示になる
- [ ] `最大: 100` を入力すると 100mm 超の画像が非表示になる

### 日付フィルタ

- [ ] `From: 2026-03-01` を入力すると 2026/3/1 以前の画像が非表示になる
- [ ] `To: 2026-03-31` を入力すると 2026/3/31 以降の画像が非表示になる
- [ ] `YYYY:MM:DD` 形式（コロン区切り）でも正しく比較される

### ステータスバー

- [ ] フィルタ適用中は「X / Y 枚 (フィルタ中)」と表示される
- [ ] フィルタなしは「Y 枚」と表示される
- [ ] インデックス中は「インデックス中… n/Y」が更新される

### リセット

- [ ] 「リセット」ボタンを押すとすべてのフィルタが解除される
- [ ] フィルタなしのとき「リセット」ボタンが無効（押せない）
