このページの内容

閲覧する ​

メインの作業画面です。フォルダ内の写真がグリッド状に並びます。

画面構成 ​

  • 左サイドバー — フィルター（ファイル種別・カメラ・ISO・焦点距離・日付・評価・ラベル・フラグ）
  • 中央グリッド — サムネイル一覧
  • メタデータバー — プレビュー・ヒストグラム・グループ内カット一覧・メタデータ（EXIF / XMP）

操作 ​

操作動作
クリック写真を選択
ダブルクリック比較画面を開く
← / → / ↑ / ↓前後の写真に移動
Space単体ビューを開く / 閉じる
スクロールグリッドをスクロール

サムネイルのバッジ ​

各サムネイルには種別を示すバッジが表示されます。

バッジ意味
SOOCカメラ出力（撮って出し JPEG）
RAWRAW ファイル
現像済み現像済みバリアント
判定不能種別を自動判定できなかったファイル

詳細はラベリングを参照してください。
