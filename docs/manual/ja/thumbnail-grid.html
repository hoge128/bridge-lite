サムネイルグリッド ​

メインの作業画面です。フォルダ内の写真がグリッド状に並びます。

画面構成 ​

  • 左サイドバー — フィルター（ファイル種別・カメラ・ISO・焦点距離・日付・評価・ラベル・フラグ）
  • 中央グリッド — サムネイル一覧
  • 右サイドバー — 選択中の写真の EXIF・ヒストグラム・評価

操作 ​

操作動作
クリック写真を選択
← / →前後の写真に移動
Spaceフルレズビューアを開く / 閉じる
Tab撮って出し・RAW・現像済みを切り替え
スクロールグリッドをスクロール

サムネイルのバッジ ​

各サムネイルには状態を示すバッジが表示されます。

  • SOOC — 撮って出し（カメラ JPEG）
  • RAW — RAW ファイル
  • Developed / 現像済み — 現像済みバリアント
  • 重複バッジ — 同一内容のファイルが複数存在する場合

サムネイルサイズの変更 ​

グリッド右上のスライダーでサムネイルのサイズを変更できます。

Pager
前のページフォルダを開く
次のページ写真を評価する
