# BridgeLite (Mac) 0.5.0

> Mac App Store 初回リリース。iOS 版と同じ「BridgeLite」レコードに macOS 版として追加（Universal Purchase）。

## Promotional Text

**日本語**
RAW+JPG 同時撮影派のフォトグラファーへ。何千枚の中から「残す一枚」を選ぶ作業を、軽快に。BridgeLite は重い現像ソフトを起動せずに、セレクト作業だけをすばやく終わらせるために作られています。

**English**
For RAW+JPG shooters: quickly pick your keepers from thousands of shots — no heavy software needed. BridgeLite is built for one thing: fast, focused photo selection.

## What's New

**日本語**
BridgeLite が Mac App Store に登場しました。

撮影後、何千枚もの RAW+JPG から「残す一枚」を選ぶ作業に特化した、軽量ビュワーです。Lightroom や Bridge を起動するほどでもない「セレクトだけ」を、速く・正確に終わらせます。

- RAW+JPG をひとつの撮影結果として束ね、ワンタップで JPG→RAW→現像バリエーションを切り替えて比較
- ファイルを一切変更しない設計。書き込むのはレーティングのみ（XMP サイドカー）で、RAW 本体はそのまま
- Image I/O・GCD・SQLite キャッシュによる高速サムネイルと滑らかな 60fps スクロール
- EXIF（カメラ・レンズ・ISO・シャッター・絞り）での並べ替え・絞り込み
- メモリカードやネットワークドライブからの読み取り専用閲覧にも安心

**English**
BridgeLite arrives on the Mac App Store.

It's a lightweight viewer built for one job: choosing which photos to keep from thousands of RAW+JPG frames after a shoot. When launching Lightroom or Bridge just to cull is overkill, BridgeLite gets the selection done — fast and accurately.

- Treats RAW+JPG as one shot; toggle JPG → RAW → retouched variations with a single tap to compare
- Never modifies your files — only ratings are written, to XMP sidecars, leaving your RAW untouched
- Fast thumbnails and smooth 60 fps scrolling via Image I/O, GCD and an SQLite cache
- Sort and filter by EXIF (camera, lens, ISO, shutter, aperture)
- Safe, read-only browsing straight from memory cards or network drives
