# Bridge Lite iOS 0.1.1

## Promotional Text

**日本語**
RAW+JPG 同時撮影派のフォトグラファーへ。何千枚の中から「残す一枚」を選ぶ作業を、軽快に。Bridge Lite は重い現像ソフトを起動せずに、セレクト作業だけをすばやく終わらせるために作られています。

**English**
For RAW+JPG shooters: quickly pick your keepers from thousands of shots — no heavy software needed. Bridge Lite is built for one thing: fast, focused photo selection.

## What's New

**日本語**
- ダブルタップ時のレース条件と評価伝播のバグを修正
- EXIF 索引をサムネイル読み込みと並行処理し、スキャン速度を改善
- ピクセルレベルグルーピング設定を追加（デフォルト: オフ）
- SQLite 接続を永続化し、フォルダ読み込み時のオーバーヘッドを削減

**English**
- Fixed a race condition on double-tap and a bug in rating propagation
- EXIF indexing now runs in parallel with thumbnail loading for faster scanning
- Added pixel-level grouping option (off by default)
- Persistent SQLite connection reduces overhead when loading folders
