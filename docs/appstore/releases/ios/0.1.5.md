# Bridge Lite iOS 0.1.5

## Promotional Text

**日本語**
RAW+JPG 同時撮影派のフォトグラファーへ。何千枚の中から「残す一枚」を選ぶ作業を、軽快に。Bridge Lite は重い現像ソフトを起動せずに、セレクト作業だけをすばやく終わらせるために作られています。

**English**
For RAW+JPG shooters: quickly pick your keepers from thousands of shots — no heavy software needed. Bridge Lite is built for one thing: fast, focused photo selection.

## What's New

**日本語**
iPad に対応しました。

詳細画面はズームトランジションで開き、Photos アプリと同じスワイプで閉じる操作に対応しています。横画面では写真の隣に 2×4 の EXIF グリッドが並ぶレイアウト、縦画面では画像の下に情報カードが並ぶレイアウトに自動で切り替わります。Stage Manager やマルチタスクのウィンドウサイズ変更にも追従します。

スワイプで閉じる際は、閉じるボタン・レーティング・ラベルなどの UI 要素がグリッドに合わせてフェードアウトし、すっきりと閉じられます。

- カラーラベルのコントロールを改善しました。選択中のラベルにチェックマークが表示されます
- 自動一時解放（操作なしで一定時間後にフォルダを解放してメモリを節約する機能）の初期値を 5 分に変更しました
- 詳細画面のフル解像度画像キャッシュをメモリ使用量に応じて動的に管理するようになりました
- iPhone のフォト情報カードのデザインを改善しました

**English**
iPad support is here.

The detail view opens with a smooth zoom transition and closes with the same swipe gesture you know from Photos. In landscape, EXIF data is displayed in a 2×4 grid alongside the photo. In portrait, info cards are stacked below the image. The layout adapts automatically to Stage Manager and multitasking window sizes.

When swiping to close, the close button, rating, color labels, and other UI elements fade out in sync with the gesture for a clean, seamless exit.

- Redesigned color label control — the selected label now shows a checkmark
- The auto-release timeout (which frees folder memory after inactivity) now defaults to 5 minutes
- Full-resolution image cache in the detail view is now dynamically managed based on available memory
- Improved the photo info card design on iPhone
