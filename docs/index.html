Developed. Camera JPEG. RAW.
One folder, understood at a glance.

撮影後のフォルダには、撮って出し・RAW・現像済みが混在する。どれが現像済みで、どれがまだか——気づけば把握できなくなっている。bridge-lite でフォルダを開けば、三種の状態と評価がひと目でわかる。

In a folder of camera JPEGs, RAWs, and developed files, bridge-lite tracks which files have been developed and what ratings they carry — your current position in the workflow.

bridge-lite の特徴

Features

グルーピング機能

Grouping

撮って出し・RAW・現像済み。
同じ写真を3つ、並べる。

Camera JPEG. RAW. Developed.
The same photo, three ways.

現像した結果が、いつも正解とは限りません。カメラ出力の方が素直に良かったり、現像を重ねるうちに元の色調を見失ってしまうことも。これらの過程を、ひとつのグループとして扱うことができます。

Developed isn't always the right answer. Sometimes the camera JPEG is simply better, and sometimes repeated edits make you lose track of where you started. BridgeLite treats all three stages as one group.

閲覧・評価・比較

Browse. Evaluate. Compare.

写真の整理に集中。

Focus on organizing your photos.

BridgeLite がやることは——写真を見る、評価する、比べるの3つだけです。現像やレタッチなどは、いつも使っているツールをご活用ください。評価はキーボードショートカットで高速に行えるので、大量の写真でもサクサク進みます。0〜5 星の評価は XMP サイドカーに書き込まれるため、Lightroom や Capture One にそのまま引き継げます。

BridgeLite does just three things: browse, evaluate, and compare. For developing and retouching, keep using the tools you already know. Keyboard shortcuts let you rate photos quickly, so even large batches stay manageable. Ratings (0–5 stars) are written to XMP sidecars and carry over to Lightroom or Capture One as-is.

可搬性のある設計

Portable by design

そこにあるファイルがすべて。

The files are all that matter.

BridgeLite は独自のデータベースを持ちません。評価などの情報はすべて XMP サイドカーに書き込まれるため、Lightroom や Capture One など、どのソフトウェアからでも読み書きできます。BridgeLite を使わなくなっても、写真のデータはそのまま残ります。

bridge-lite has no proprietary database. All information — including ratings — is written to XMP sidecars, making it readable by any software, including Lightroom and Capture One. Even if you stop using bridge-lite, your photo data stays intact.

BridgeLite は開発者個人のプロジェクトです。開発者自身が Mac を日常的に使っているため、まず macOS 版からのリリースとなりました。最高のパフォーマンスを実現するためには、Mac では SwiftUI、Windows では WinUI 3 といったプラットフォーム固有の UI フレームワークが必要と考えています。一方、コア機能は Rust で開発しているため、UI より下の処理については将来的に共通化できる見込みです。

What's next

  • New features are actively planned. We'd love to hear what you need.
  • Currently available in Japanese and English only. Additional languages may be considered in the future.
  • A Windows version is under consideration if there is sufficient demand.
  • Open-sourcing the code is currently being considered.
  • Feature requests and bug reports are welcome via the contact form.

BridgeLite is a personal project. It launched on macOS first because the developer uses Mac day-to-day. Delivering the best experience requires platform-native UI frameworks — SwiftUI on Mac, WinUI 3 on Windows. That said, the core functionality is built in Rust, so the underlying logic could be shared across platforms in the future.
