BridgeLite 0.4.1

New Features

  • Clear buttons added to each section of the filter panel — reset individual filters without touching the others
  • XMP sidecar mode UX improvements — clearer status and feedback when writing ratings to sidecar files

Fixes

  • Metadata sidebar content no longer gets clipped by the scrollbar
  • Removed the calendar button from the toolbar (the date filter remains available in the filter panel)

Performance

  • Thumbnail SQLite writes are now batched, eliminating beachball freezes caused by WAL contention during large folder scans
