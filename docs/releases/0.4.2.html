BridgeLite 0.4.2

New Features

  • Rubber band selection — drag across the grid to select multiple photos; hold Shift or ⌘ to extend the selection
  • Shimmer animation during scanning — thumbnails, sidebar preview, EXIF panel, and filter histograms now display a loading skeleton instead of a static grey placeholder

Filter UI Improvements

  • Filter histograms are now more compact — reduced height and smaller range handles
  • Fixed filter panel aggregate views (camera/lens lists, histograms, rating counts) not clearing when opening a new folder

Fixes

  • Fixed EXIF not appearing in the metadata panel and RAW+JPG pairs not being grouped on the first scan of a folder
  • After deleting a photo, focus now moves to the next photo in the grid rather than the previous one (consistent with the item shifting up to fill the gap)

新機能
