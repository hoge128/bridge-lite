# フィルタリング

左サイドバーのフィルターパネルで、表示する写真を絞り込めます。

## フィルターの種類

| フィルター | 内容 |
|---|---|
| ファイル種別 | 撮って出し / RAW / 現像済み |
| カメラ機種 | 撮影に使ったカメラ |
| ISO | ISO 感度の範囲 |
| 焦点距離 | 焦点距離の範囲 |
| 日付 | 撮影日 |
| 評価 | 星の数（0〜5） |
| カラーラベル | 赤・黄・緑・青・紫 |
| フラグ | Pick / Reject / 未評価 |

## フィルターの組み合わせ

複数のフィルターを同時に適用できます。例えば「Pick フラグが付いた RAW のみ」といった絞り込みが可能です。

## フィルターのリセット

サイドバー上部の「リセット」ボタンで、すべてのフィルターを解除します。
