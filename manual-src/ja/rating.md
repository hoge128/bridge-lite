# 写真を評価する

bridge-lite のレーティングはすべて **XMP サイドカーファイル**に書き込まれます。RAW ファイル本体は変更しません。Lightroom・Capture One・Adobe Bridge とそのまま互換します。

## 星評価

0〜5 の星評価を**キーボードショートカット**または**右クリックメニュー**から付けられます。評価値は XMP の `xmp:Rating` フィールドに書き込まれます。このフィールドは Lightroom・Capture One・Adobe Bridge・FastRawViewer など多くのソフトウェアで共通して読み書きされる標準フィールドです。

### ショートカット

ショートカットは設定ページの **評価 / ラベルキー** から変更できます。

| 設定値 | ショートカット |
|---|---|
| 数字キー | `0`〜`9` |
| ⌘ + 数字 | `⌘0`〜`⌘9` |
| ^ + 数字 | `^0`〜`^9` |

| キー | 評価 |
|---|---|
| `0` | 評価なし |
| `1` | ★☆☆☆☆ |
| `2` | ★★☆☆☆ |
| `3` | ★★★☆☆ |
| `4` | ★★★★☆ |
| `5` | ★★★★★ |

### 右クリックメニュー

サムネイルを右クリック → **評価** から同じ操作が行えます。マウス操作のみで完結させたい場合に便利です。

## グループ写真への評価

バースト撮影などでグループ化された写真に評価を付けると、**グループ内の全カットに同じ評価が伝搬します**（デフォルト動作）。個別のカットだけ評価を調整したい場合は、メタデータバーから操作します。

詳細な動作・操作手順は[評価の伝搬](./rating-spec)を参照してください。


## カラーラベル

ラベル情報は `xmp:Label` および `photoshop:LabelColor` に書き込まれます（Adobe Bridge 互換）。カラーラベルも**ショートカット**と**右クリックメニュー**の両方から設定できます。

| キー | ラベル |
|---|---|
| `6` | 赤 |
| `7` | 黄 |
| `8` | 緑 |
| `9` | 青 |

## XMP の保存先

| ファイル種別 | 保存先 |
|---|---|
| RAW（`.arw` / `.cr3` など） | 同名の `.xmp` サイドカー |
| JPEG | ファイルに直接埋め込み |

## Lightroom への引き継ぎ

bridge-lite でレーティングを付けた後、Lightroom でフォルダを開くと評価がそのまま反映されます（XMP の自動読み込みが有効な場合）。
