# bridge-lite とは

bridge-lite は、RAW+JPG 同時撮影をするフォトグラファーのための**軽量画像セレクトビュワー**です。

「撮って出し（JPEG）」「RAW」「現像済み」が入り混じる撮影後のフォルダの中で、どのファイルを現像したか、どんな評価がついているかを把握する——その「現在地の確認」を担います。

## 何をするアプリか

bridge-lite がやることは三つだけです。

- **見る** — サムネイルグリッドで大量の写真を素早くスクロール
- **評価する** — 0〜5 星の XMP レーティングをキーボードで付ける
- **比べる** — 撮って出し・RAW・現像済みを一枚として行き来する

現像・レタッチ・書き出しは行いません。それらはすでにあなたが使っている Lightroom や Capture One に委ねます。

## 何をしないか

| しないこと | 担うツール |
|---|---|
| 現像・色補正 | Lightroom / Capture One / Darkroom |
| 書き出し・リサイズ | 現像ツール |
| カタログ管理 | 現像ツール |
| クラウド共有 | スコープ外 |

## ファイルは変更しない

閲覧・スクロール・フィルタリングのいかなる操作においても、元ファイルのバイト列・タイムスタンプ・パーミッションは一切変更しません。メモリカードやネットワークドライブからも安心して使えます。

レーティング情報は XMP サイドカーファイルに書き込まれます。RAW ファイル本体は変更しません。
