# キーボードショートカット

bridge-lite はキーボードだけでセレクト作業を完結できるように設計されています。

## ナビゲーション

| キー | 動作 |
|---|---|
| `←` | 前の写真 |
| `→` | 次の写真 |
| `Tab` | バリアント切替（撮って出し → RAW → 現像済み） |
| `Space` | フルレズビューアを開く / 閉じる |
| `Esc` | ビューアを閉じる |

## 評価

| キー | 動作 |
|---|---|
| `0` | 評価なし |
| `1` | ★☆☆☆☆ |
| `2` | ★★☆☆☆ |
| `3` | ★★★☆☆ |
| `4` | ★★★★☆ |
| `5` | ★★★★★ |
| `P` | Pick フラグ |
| `X` | Reject フラグ |
| `U` | フラグを外す |

## カラーラベル

| キー | ラベル |
|---|---|
| `6` | 赤 |
| `7` | 黄 |
| `8` | 緑 |
| `9` | 青 |

## 表示

| キー | 動作 |
|---|---|
| `G` | グループ比較ビューを開く / 閉じる |
