# Filtering

Use the filter panel in the left sidebar to narrow down the photos shown in the grid.

## Available filters

| Filter | Description |
|---|---|
| File type | Camera JPEG / RAW / Developed |
| Camera model | The camera body used |
| ISO | ISO sensitivity range |
| Focal length | Focal length range |
| Date | Shooting date |
| Rating | Star count (0–5) |
| Color label | Red / Yellow / Green / Blue / Purple |
| Flag | Pick / Reject / Unflagged |

## Combining filters

Multiple filters can be active at the same time. For example: "RAW files with a Pick flag only."

## Resetting filters

Click the **Reset** button at the top of the sidebar to clear all active filters.
