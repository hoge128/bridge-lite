# Filters

The filters in the left sidebar let you narrow down the photos displayed in the grid.

## Filter options

| Filter | Description |
|---|---|
| File type | Filter by SOOC / RAW / Developed / Indeterminate |
| Camera | Filter by camera model |
| ISO | Filter by ISO value |
| Focal length | Filter by focal length |
| Date | Filter by shooting date |
| Rating | Filter by star rating |
| Label | Filter by label |
| Flag | Filter by Pick / Reject flag |
