# Thumbnail grid

The main working view. All photos in the folder are displayed as a scrollable grid.

## Layout

- **Left sidebar** — Filters (file type, camera, ISO, focal length, date, rating, label, flag)
- **Center grid** — Thumbnail view
- **Right sidebar** — EXIF, histogram, and rating for the selected photo

## Controls

| Action | Result |
|---|---|
| Click | Select a photo |
| `←` / `→` | Move to previous / next photo |
| `Space` | Open / close full-res viewer |
| `Tab` | Switch between camera JPEG, RAW, and developed |
| Scroll | Scroll the grid |

## Thumbnail badges

Each thumbnail shows a badge indicating its type:

- `SOOC` — Straight out of camera (camera JPEG)
- `RAW` — RAW file
- `Developed` — Developed variant
- Duplicate badge — Multiple files with identical content

## Thumbnail size

Use the slider in the top-right of the grid to adjust thumbnail size.
