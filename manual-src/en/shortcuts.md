# Keyboard shortcuts

bridge-lite is designed so that an entire culling session can be completed without touching the mouse.

## Navigation

| Key | Action |
|---|---|
| `←` | Previous photo |
| `→` | Next photo |
| `Tab` | Switch variant (Camera JPEG → RAW → Developed) |
| `Space` | Open / close full-res viewer |
| `Esc` | Close viewer |

## Rating

| Key | Action |
|---|---|
| `0` | No rating |
| `1` | ★☆☆☆☆ |
| `2` | ★★☆☆☆ |
| `3` | ★★★☆☆ |
| `4` | ★★★★☆ |
| `5` | ★★★★★ |
| `P` | Pick flag |
| `X` | Reject flag |
| `U` | Clear flag |

## Color labels

| Key | Label |
|---|---|

| `8` | Green |

## View

| Key | Action |
|---|---|
