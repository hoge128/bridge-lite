# Full-res viewer

Press `Space` to open the selected photo at full resolution.

## Controls

| Key | Action |
|---|---|
| `Space` | Open / close viewer |
| `←` / `→` | Previous / next photo |
| `Tab` | Switch between camera JPEG, RAW, and developed |
| `0`–`5` | Star rating |
| `P` / `X` | Pick / Reject flag |
| `Esc` | Close viewer |

## EXIF overlay

The bottom-left of the viewer shows shooting information:

- Aperture (f-number)
- Shutter speed
- ISO
- Focal length
- Camera model
